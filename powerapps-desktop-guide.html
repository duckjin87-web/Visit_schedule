1Teams 팀 만들기 (= SharePoint 사이트)

이 단계가 끝나면: 파트원이 모두 들어와 있는 Teams 팀이 생기고, 같이 만들어진 SharePoint 사이트 주소를 알게 됩니다. 팀 구성원은 자동으로 사이트의 데이터를 보고 고칠 수 있습니다.
이미 쓰는 팀이 있다면 그 팀을 그대로 써도 됩니다. 그 경우 4번 단계(사이트 열기)부터 하세요.
  1. Teams 앱(또는 teams.microsoft.com)을 엽니다. 왼쪽 세로 메뉴에서 팀 (Teams)을 누릅니다.
  2. 팀 목록 위쪽의 + (또는 팀 참가 또는 만들기 (Join or create a team)) → 팀 만들기 (Create team)를 누릅니다.
    • 팀 이름: 방문업무
    • 공개 범위: 비공개 (Private) → 만들기
  3. 구성원 추가 창이 뜨면 0단계에서 적어 둔 파트원 이름을 하나씩 입력하고 고른 뒤 추가 (Add)를 누릅니다. (나중에 팀 이름 옆 ⋯ → 구성원 추가로도 할 수 있어요.)
  4. 만든 팀의 일반 (General) 채널을 엽니다. 채널 위쪽 탭 중 파일 (Files)(또는 공유됨 (Shared))을 누르고 → SharePoint에서 열기 (Open in SharePoint)를 누릅니다. 안 보이면 채널 이름 옆 ⋯ → SharePoint에서 열기.
  5. 브라우저에 SharePoint 사이트가 열립니다. 주소창의 주소에서 /sites/팀이름까지를 복사해 메모장에 붙여 둡니다.
    예) https://회사이름.sharepoint.com/sites/방문업무
    이 주소를 사이트 주소라고 부르겠습니다. 사이트 왼쪽 위 이름(방문업무)을 누르면 사이트 첫 화면(홈)으로 갑니다.

꼭 지킬 것 목록 이름과 열 이름은 표에 적힌 글자 그대로, 띄어쓰기 없이 만드세요(라이브러리 이름 '방문 리포트'만 띄어쓰기 있음). 앱 수식이 이 이름을 그대로 씁니다. 선택 항목(임시저장 등)도 글자 그대로. 헷갈리면 회색 글자를 눌러 복사해 붙여 넣으세요.

2-1. 목록 만드는 방법 (다섯 목록 모두 같음)

  1. 사이트 홈에서 위쪽 + 새로 만들기 (+ New) → 목록 (List)을 누릅니다.
  2. 빈 목록 (Blank list)을 누릅니다.
  3. 이름 칸에 목록 이름을 넣고, 사이트 탐색에 표시가 켜져 있는지 확인한 뒤 만들기 (Create).
  4. 빈 표에 제목 (Title) 열 하나만 있습니다. 제목 글자 → 열 설정 → 이름 바꾸기 → 상호명 → 저장. (다섯 목록 모두 첫 열은 '상호명' 또는 '지역')

2-2. 열(칸) 추가하는 방법

  1. 표 맨 오른쪽 머리글의 + 열 추가 (+ Add column)를 누릅니다.
  2. 종류를 고르고 다음: 한 줄 텍스트 (Single line of text), 여러 줄 텍스트 (Multiple lines of text), 선택 (Choice), 날짜 및 시간 (Date and time), 사용자 (Person), 숫자 (Number), 예/아니요 (Yes/No)
  3. 이름을 넣고 표의 설정대로 고친 뒤 저장.
    • 선택: 선택 항목을 칸마다 하나씩, 모자라면 + 선택 항목 추가. 기본값을 표대로, 사용자 지정 값 허용은 끕니다.
    • 날짜 및 시간: 시간 포함을 끕니다.
    • 여러 줄 텍스트: 추가 옵션 → 서식 있는 텍스트 사용을 끕니다.
    • 사용자: 참석자 두 열만 추가 옵션에서 여러 항목 선택 허용을 켭니다.
    • 숫자: 추가 옵션 → 소수 자릿수 0.
  4. 표의 순서대로 만드세요. 방문처 목록은 앞의 14개 열 순서가 3단계 엑셀 붙여 넣기 순서와 같아야 합니다.

이 단계가 끝나면: 왼쪽에서 업체를 고르면 오른쪽 스크롤 영역에 실제 방문일 · 점수(협/생 + 품질보증) · 특이사항 · 자료 링크 · 제조 CAPA · 생산 CAPA · 버튼이 보이고, 방문완료 · CAPA요청 · 등록취소 · 등록완료를 처리합니다.

9-0. 세로 스크롤 영역 만드는 법 (먼저 읽기)

  1. ResultScreen 클릭 → + 삽입 → 위쪽 분류 레이아웃 (Layout) → 세로 컨테이너 (Vertical container). 이름 conRes, 위치 · 크기는 카드대로.
  2. 트리 뷰에서 conRes를 클릭해 선택한 상태로 + 삽입 → 레이아웃 → 컨테이너 (Container). conRes 안으로 들어갑니다. 이름 secRInfo.
  3. secRInfo 속성 창에서 유연한 높이 (Flexible height)를 끄고 높이를 카드대로 넣습니다. 가로는 자동으로 꽉 찹니다(안 차면 컨테이너에서 맞춤 (Align in container) → 늘이기).
  4. 같은 방법으로 secRScore, secRMake, secRProd, secRBtns를 만듭니다. 트리 뷰 순서 = 화면의 위 → 아래 순서입니다(순서가 틀리면 트리 뷰에서 끌어서 바꿉니다).
  5. 구역(예: secRScore)을 클릭한 상태에서 컨트롤을 넣으면 그 구역 안으로 들어가고, 카드의 X · Y는 구역 왼쪽 위 기준입니다.
  1. F5 → 업체 고르기 → CAPA 표에 + 줄 추가 → 설비CAPA 60000, 보유대수 1을 넣고 다른 칸을 누르면 일 60,000 · 월 1,200,000이 자동으로 채워지는지 확인합니다.
  2. 협/생 점수 84 → 환산 42 · 총점이 보이고 방문완료가 켜지는지 확인합니다.
  3. CAPA요청 → 왼쪽 목록에 D+0이 보이는지, 등록완료 → 목록에서 빠지는지 확인합니다. Ctrl+S.
