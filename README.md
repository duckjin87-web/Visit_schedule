# 방문예정처 관리

CosmeDB의 **3번 방문예정처 탭**만 분리한 단독 실행 버전입니다.
신규 방문처의 일정 협의 → 방문 확정 → 방문 결과까지 한 표에서 관리합니다.

## 바로 사용
- GitHub Pages: 저장소 `Settings → Pages → Branch: main / (root)` 저장 후 `https://<계정>.github.io/<저장소명>/`
- 로컬: `index.html`을 브라우저로 열기 (빌드 없음)

## 주요 기능
- 진행 상태 필터 칩 (일정협의중 · 방문예정 · 방문완료 · Capa회신대기중 · 등록완료 · 방문취소 · 등록불가 · 기타)
- 가능일 자유입력 자동 인식 (`7/23~24`, `9월12일`, `9.12`, `2026-09-12`, `8/25 이후`)
- 공통 가능일 = (협생 ∩ 품보) ∩ 업체 → 확정 방문일 선택지로 제공
- 방문 예정시간 입력 시 이동거리·소요시간·출발시각 추정 (세종 전의면 기준, 참고치)
- D-day, 2주 미니 캘린더(**14일 한 줄**, 확정일에 방문 업체명 표시), 방문통계, Capa 요청 7일 경과 알림
- 열 그룹 토글, 열너비 드래그/자동맞춤 (업체명 열은 **불투명 틀고정**)
- **다크 / 라이트 / 시스템 테마 전환** (우측 상단 🌓 버튼, 선택값 저장)
- 신규 등록(**중복 업체명 확인**·소개자료 링크 포함), **업체 삭제**(🗑, **실행취소 지원**), Excel(.xlsx) 저장
- **Excel 불러오기** — 기존 수동 조사 양식을 업로드하면 열 제목을 카테고리별로 자동 매칭해 채움
  - 헤더 동의어 자동 인식(예: `상호명/회사명→업체명`, `전화번호/휴대폰→연락처`, `진행상태→상태`)
  - **업로드 미리보기** — 열 매핑과 신규/갱신 건수를 확인한 뒤 적용
  - 업체ID·업체명이 같으면 **기존 행의 빈 칸만 채움**(기존 값 보존), 없으면 신규 추가
  - 상태 라벨→내부값(`방문완료→완료` 등), 날짜 `2026-10-05`, 시간 `10시반→10:30` 자동 정규화
- **데이터 관리(⋯ 데이터)** — JSON 백업 저장 / 복원, 데모 다시 불러오기, 전체 비우기(모두 실행취소 가능)
- 소개자료 링크에 `https://…` 입력 시 **새 탭 열기(↗)** 버튼 제공

> ⚠️ **팀 공유 안내:** 데이터는 브라우저(localStorage)에만 저장되어 **실시간 팀 공유·동시편집은 되지 않습니다.**
> 공유·이관·백업은 **⋯ 데이터 → JSON 백업/복원** 또는 **Excel 저장/불러오기**를 사용하세요.
> (실시간 다중 사용자 동기화가 필요하면 구글시트/Firebase 등 별도 백엔드 연동이 필요합니다.)

## 데이터 저장
- 브라우저 `localStorage`(`cosmedb_visits_v1`)에 자동 저장 — **기기·브라우저별로 따로 저장**되며 팀원과 공유되지 않습니다.
- 첫 실행 시 `js/data.js`의 데모 18건(기존 8 + 시나리오 검증용 10)이 들어갑니다. 실제 데이터로 시작하려면 `const RAWVISIT = [];`로 비운 뒤 브라우저 저장 데이터를 삭제하세요.
  - 삭제: 개발자도구 콘솔에서 `localStorage.removeItem('cosmedb_visits_v1')` 후 새로고침
- 백업은 **Excel 저장**을 사용하세요.

## 파일 구조
```
index.html      화면 뼈대
css/style.css   스타일 (Material 3 토큰, 다크모드 포함)
js/data.js      데모 데이터 (RAWVISIT)
js/app.js       로직 — 날짜 파싱, 이동 추정, 표 렌더링, 통계, 등록, 엑셀
```

## 수정 포인트 (js/app.js)
| 바꾸고 싶은 것 | 위치 |
|---|---|
| 상태 종류·색상 | `VST` |
| 열 추가/순서/너비 | `VCOLS`, 그룹은 `VGROUPS` |
| 셀 입력 방식 | `vcell()` 의 `case` |
| 지역별 이동시간 | `CITY`, `PROV` (km, 분) · 여유시간 `BUF` |
| 선정주체 선택지 | `vcell()` → `case "picker"` |
| 저장 키 | `loadVisits()` / `saveVisits()` |
