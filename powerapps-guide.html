순서대로 따라 하면 앱이 완성됩니다

이 안내서는 SharePoint 목록에 데이터를 두고, Power Apps로 화면을 만들고, Power Automate로 알림을 보내는 방문 업무 앱을 처음부터 만드는 방법입니다. 완성 모습은 Power Apps 예상 목업과 같은 구조입니다.

② 데이터 표SharePoint 목록 3개 + 라이브러리 1개
③ 앱 화면업무 단계 탭 5개
④ 자동화알림 흐름 3개 + 리포트 1개
11/4 개정 화면을 업무 단계 탭 5개(일정 조율 · 방문 예정 · 결과·판정 · 전체 업체 · 통계)로 바꿨습니다. 통계 탭(대시보드형)과 이를 위한 실제방문일 · 판정일 열, 판정이 나면 리포트 PDF를 자동 저장하는 흐름 ④를 더했습니다. 사전 방문평가 배점과 vendor-scout 연계는 넣지 않습니다.
이전 안내서로 이미 만들던 분: 목록에 열 3개만 더하고(2-3 아래 안내), HomeScreen과 왼쪽 메뉴는 지운 뒤 4-5단계부터 다시 따라 하세요. 일정 조율 · 방문 목록 · 결과 화면의 수식은 그대로 쓰고 위치만 옮기면 됩니다.
읽는 법 단계마다 왼쪽 체크박스를 누르면 진행률이 저장됩니다(이 브라우저에만). 파란 글씨는 누를 메뉴, 괄호 안 (영어)는 화면이 영어로 보일 때의 이름입니다. 회색 상자의 복사를 누르면 값이 복사되니 붙여 넣기(Ctrl+V)만 하세요.
메뉴 이름 Microsoft 화면은 업데이트로 이름이나 위치가 조금씩 바뀝니다. 한국어 이름이 안 보이면 괄호 안 영어 이름이나 비슷한 단어를 찾으세요. Power Apps는 왼쪽 삽입(+) 창의 검색칸에 이름을 치면 거의 다 찾을 수 있습니다.

0시작 전 준비

이 단계가 끝나면: 만들 때 필요한 것이 모두 손에 있습니다.
  1. PC와 Microsoft Edge 또는 Chrome 브라우저를 준비합니다. (휴대폰으로는 만들 수 없어요. 만든 앱을 쓰는 것만 휴대폰으로 가능합니다.)
  2. 회사 계정(회사 메일 주소)으로 office.com에 로그인되는지 확인합니다.
  3. 기존 정리 파일(엑셀)을 PC에 받아 둡니다. 지금 웹앱을 쓰고 있다면 웹앱의 Excel 저장으로 받은 파일도 됩니다.
  4. 같이 쓸 파트원 10명의 이름(또는 메일) 목록을 메모장에 적어 둡니다.
  5. 이 안내서를 한쪽 화면에, 작업 화면을 다른 쪽에 띄우면 편합니다. (모니터가 하나면 창 두 개를 좌우로 나누기: 창을 클릭하고 Windows 키 + ←, 다른 창은 Windows 키 + →)

1Teams 팀 만들기 (= SharePoint 사이트)

이 단계가 끝나면: 파트원이 모두 들어와 있는 Teams 팀이 생기고, 같이 만들어진 SharePoint 사이트 주소를 알게 됩니다. 팀 구성원은 자동으로 사이트의 데이터를 보고 고칠 수 있습니다.
이미 쓰는 팀이 있다면 그 팀을 그대로 써도 됩니다. 그 경우 4번 단계(사이트 열기)부터 하세요.
  1. Teams 앱(또는 teams.microsoft.com)을 엽니다. 왼쪽 세로 메뉴에서 팀 (Teams)을 누릅니다.
  2. 팀 목록 위쪽의 + (또는 팀 참가 또는 만들기 (Join or create a team)) → 팀 만들기 (Create team)를 누릅니다.
    • 팀 이름: 방문업무
    • 공개 범위: 비공개 (Private) → 만들기
  3. 구성원 추가 창이 뜨면 0단계에서 적어 둔 파트원 이름을 하나씩 입력하고 고른 뒤 추가 (Add)를 누릅니다. (나중에 팀 이름 옆 ⋯ → 구성원 추가로도 할 수 있어요.)
  4. 만든 팀의 일반 (General) 채널을 엽니다. 채널 위쪽 탭 중 파일 (Files)(또는 공유됨 (Shared))을 누르고 → SharePoint에서 열기 (Open in SharePoint)를 누릅니다. 안 보이면 채널 이름 옆 ⋯ → SharePoint에서 열기.
  5. 브라우저에 SharePoint 사이트가 열립니다. 주소창의 주소에서 /sites/팀이름까지를 복사해 메모장에 붙여 둡니다.
    예) https://회사이름.sharepoint.com/sites/방문업무
    이 주소를 사이트 주소라고 부르겠습니다. 사이트 왼쪽 위 이름(방문업무)을 누르면 사이트 첫 화면(홈)으로 갑니다.

2SharePoint 목록 3개 · 문서 라이브러리 1개 만들기

이 단계가 끝나면: 데이터를 담을 표(목록) 3개가 생깁니다 — 방문처(업체 한 곳 = 한 줄), 방문후보일(후보 날짜 하나 = 한 줄), 지역이동시간(출발 시각 계산용). 그리고 리포트 PDF가 쌓일 방문 리포트 문서 라이브러리.
꼭 지킬 것 목록 이름과 열 이름은 표에 적힌 글자 그대로, 띄어쓰기 없이 만드세요. 앱 수식이 이 이름을 그대로 씁니다. 선택 항목(예: 일정 조율 중)은 반대로 띄어쓰기까지 똑같이 입력해야 합니다. 헷갈리면 회색 글자를 눌러 복사해 붙여 넣으세요.

2-1. 목록 만드는 방법 (세 목록 모두 같음)

  1. 사이트 홈에서 위쪽 + 새로 만들기 (+ New) → 목록 (List)을 누릅니다.
  2. 빈 목록 (Blank list)을 누릅니다.
  3. 이름 칸에 목록 이름(예: 방문처)을 넣고, 사이트 탐색에 표시가 켜져 있는지 확인한 뒤 만들기 (Create)를 누릅니다.
  4. 빈 표가 열리고 제목 (Title)이라는 열 하나만 있습니다. 이 열의 이름을 바꿉니다: 제목 글자를 누름 → 열 설정 (Column settings) → 이름 바꾸기 (Rename) → 새 이름 입력 → 저장.

2-2. 열(칸) 추가하는 방법

  1. 표 맨 오른쪽 머리글의 + 열 추가 (+ Add column)를 누릅니다.
  2. 종류를 고르고 다음 (Next)을 누릅니다. 종류 이름: 한 줄 텍스트 (Single line of text), 여러 줄 텍스트 (Multiple lines of text), 선택 (Choice), 날짜 및 시간 (Date and time), 사용자 (Person), 숫자 (Number), 예/아니요 (Yes/No)
  3. 이름을 넣고 아래 표의 설정대로 고친 뒤 저장을 누릅니다.
    • 선택 종류: 선택 항목 칸마다 하나씩 입력, 칸이 모자라면 + 선택 항목 추가. 기본값을 표대로 고르고, 사용자 지정 값 입력 허용은 끕니다.
    • 날짜 및 시간 종류: 시간 포함 (Include time)을 끕니다.
    • 여러 줄 텍스트 종류: 추가 옵션 (More options)을 열어 서식 있는 텍스트 사용 (Use enhanced rich text)을 끕니다. (켜져 있으면 앱에 이상한 기호가 섞여요.)
    • 사용자 종류(참석자만): 추가 옵션에서 여러 항목 선택 허용 (Allow multiple selections)을 켭니다.
  4. 표의 순서대로 열을 만드세요. 3단계에서 엑셀을 붙여 넣을 때 이 순서가 맞아야 합니다.

2-3. 목록 ① 방문처

목록 이름: 방문처

#열 이름종류설정
이전 안내서로 목록을 이미 만들었다면 열 3개만 추가하세요: 실제방문일(날짜, 시간 포함 끄기), 판정일(날짜, 시간 포함 끄기), 리포트발송(예/아니요, 기본값 아니요). 그다음 목록 머리글에서 실제방문일·판정일을 끌어 Capa요청일 바로 뒤로 옮기면 3단계의 엑셀 붙여 넣기 순서와 맞습니다.

2-6. 문서 라이브러리 방문 리포트

  1. 사이트 홈에서 + 새로 만들기 (+ New) → 문서 라이브러리 (Document library) → 빈 라이브러리 (Blank library)를 누릅니다.
  2. 이름 방문 리포트(가운데 띄어쓰기 한 칸) → 만들기. 15단계 흐름이 판정 리포트를 업체명_판정일.pdf 이름으로 여기에 저장합니다. 팀 구성원은 모두 열어 볼 수 있습니다.

3기존 데이터 옮기기

이 단계가 끝나면: 지역 이동시간 54줄과 기존 정리 파일의 업체들이 SharePoint 목록에 들어갑니다. 방법은 엑셀에서 복사 → 목록의 "그리드 보기"에 붙여 넣기입니다.

3-1. 지역이동시간 붙여 넣기 (먼저 연습)

  1. 아래 지역 54줄 전체 복사 단추를 누릅니다. (시·군을 먼저, 도를 나중에 넣어야 "화성"처럼 자세한 지역이 먼저 찾아집니다.)
    — 표 머리글 없이 데이터만 복사됩니다
    복사되는 내용 보기
    지역거리km소요분
  2. SharePoint의 지역이동시간 목록을 엽니다(사이트 왼쪽 메뉴에 이름이 보여요). 위쪽 그리드 보기에서 편집 (Edit in grid view)을 누릅니다.
  3. 맨 아래 빈 줄(새 항목 추가 줄)의 지역 칸을 한 번 클릭하고 Ctrl+V를 누릅니다. 54줄이 한 번에 들어갑니다.
  4. 위쪽 그리드 보기 종료 (Exit grid view)를 누릅니다. 54줄이 저장됐는지 확인합니다.

3-2. 기존 정리 파일 준비 (엑셀)

  1. 기존 정리 파일을 엑셀로 열고, 새 시트를 하나 만듭니다(시트 탭 옆 +).
  2. 새 시트 A1 칸을 클릭하고, 아래 머리글 복사를 눌러 붙여 넣습니다. 15칸이 한 줄로 들어갑니다.
    업체명 | 상태 | 구분 | 소재지 | 업체담당자 | 연락처 | 의뢰제품 | 선정주체 | 선정사유 | 확정방문일 | 방문시간 | 방문결과 | Capa요청일 | 실제방문일 | 판정일
  3. 기존 시트에서 열마다 복사해 새 시트의 같은 이름 열 아래에 붙여 넣습니다. 없는 정보는 비워 둡니다.
  4. 상태 열의 값을 아래 표대로 바꿉니다. (엑셀 Ctrl+H = 바꾸기를 쓰면 빠릅니다. 띄어쓰기까지 정확히!)
    기존 값바꿀 값
  5. 구분은 OEM / ODM / OEM/ODM 중 하나로, 선정주체는 협력생산팀 / 품질보증팀 중 하나로 맞춥니다.
  6. 날짜(확정방문일, Capa요청일, 실제방문일, 판정일)는 2026-11-05 모양으로, 방문시간은 09:30처럼 두 자리로 맞춥니다.
  7. 소재지에는 시·군 이름이 꼭 들어가게 합니다(예: 경기 화성시 향남읍). 출발 시각 계산에 씁니다.
  8. 이미 방문한 업체는 실제방문일(다녀온 날)을, 등록 완료 · 등록 불가로 끝난 업체는 판정일도 채웁니다. 모르면 실제방문일 = 확정방문일, 판정일 = 대략의 날짜로 넣어도 됩니다. 통계 탭은 이 두 날짜로 셉니다.
가능일(자유 입력)은? "11/12~14" 같은 기존 가능일은 옮길 칸이 없습니다. 아직 일정 조율 중인 업체만, 앱이 완성된 뒤 일정 조율 화면에서 후보일로 다시 넣으면 됩니다.

3-3. 방문처에 붙여 넣기

  1. 엑셀 새 시트에서 머리글을 뺀 데이터만 선택합니다(A2부터 마지막 줄의 O열까지). 한 번에 100줄 이하씩 하는 게 안전합니다. Ctrl+C.
  2. SharePoint 방문처 목록 → 그리드 보기에서 편집 → 맨 아래 빈 줄의 업체명 칸 클릭 → Ctrl+V.
  3. 빨간 표시가 있는 칸은 값이 선택 항목과 다른 것입니다. 칸을 눌러 목록에서 다시 고릅니다.
  4. 그리드 보기 종료. 주담당·참석자(사용자 열)는 붙여 넣기가 안 되니 나중에 앱이나 목록에서 한 명씩 고릅니다. 적어도 진행 중인 건은 주담당을 채워 두세요(Capa 회신 독촉 알림이 주담당에게 갑니다).
이관이 끝나면 예전 웹앱이나 엑셀에는 더 이상 입력하지 마세요. 두 곳에 나눠 적으면 데이터가 어긋납니다.

4Power Apps 앱 만들고 데이터 연결하기

이 단계가 끝나면: 빈 태블릿 앱이 열리고, 목록 3개가 연결되고, 탭 5개에 해당하는 화면 5개(이름만)가 준비됩니다.

4-1. 빈 앱 만들기

  1. make.powerapps.com에 접속합니다(회사 계정 자동 로그인). 오른쪽 위 환경 (Environment)이 회사 기본 환경인지 봅니다. IT에서 정해 준 환경이 있으면 그걸 고르세요.
  2. 홈 화면의 빈 캔버스로 시작 (Start with a blank canvas)을 누르고 태블릿 크기 (Tablet size)를 고릅니다.
    • 안 보이면: 왼쪽 메뉴 + 만들기 (Create) → 빈 앱 (Blank app) → 빈 캔버스 앱의 만들기 → 형식 태블릿.
  3. 앱 이름: 방문예정처 → 만들기. 처음 열 때 환영 창이 뜨면 건너뛰기 (Skip)를 누릅니다.
  4. 바로 Ctrl+S(저장)를 한 번 누릅니다. 앞으로 10분마다 Ctrl+S를 누르는 습관을 들이세요.
